# Lydia & Regan

A minimal FastAPI journal demo with an interactive API page.

## Run locally

Install Python 3.10 or later. From the repository root, create a virtual environment:

```text
cd lydia-regan
python -m venv .venv
```

On Windows, run these commands in PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

On macOS or Linux, use these equivalent commands. If your system uses `python3`, use it for the virtual environment command above.

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). The root URL `/` also redirects to `/docs`. Stop the server with `Ctrl+C`.

In PyCharm, select the virtual environment's Python interpreter and run `main.py`.

## Endpoints and data

| Method | Path | Result |
| --- | --- | --- |
| GET | `/entries` | Returns all journal entries as a JSON array. |
| POST | `/entries` | Creates a journal entry and returns it with status `201`. |

`EntryCreate` accepts a `title` of 1–100 characters and `content` of 1–10,000 characters. Leading and trailing whitespace is removed; empty or whitespace-only values are rejected. `Entry` adds a server-generated integer `id` and UTC `created_at` timestamp to these fields.

## Try the demo

1. Expand **GET /entries**, click **Try it out**, then **Execute**. A fresh server returns `[]` with status `200`.
2. Expand **POST /entries**, click **Try it out**, and submit:

   ```json
   {
     "title": "My first journal entry",
     "content": "Today I completed the Lydia and Regan FastAPI demo."
   }
   ```

3. Check the `201` response, including the generated `id` and `created_at`.
4. Execute **GET /entries** again to see the saved entry.
5. Try omitting `content` or submitting an empty field to see a `422` validation response.

`requests.http` contains the same examples for an HTTP client that supports this file format.

## Files and scope

- `main.py`: models, in-memory storage, routes, and server startup.
- `requirements.txt`: runtime dependencies.
- `requests.http`: sample API requests.

Data is stored in memory and is cleared when the server restarts. Run a single server worker. This demo provides creation and listing only; it does not include a database, authentication, editing, or deletion.

The `/docs` web page is generated by FastAPI while the server runs. Uploading these files to GitHub stores the source code; it does not provide a publicly running backend.
