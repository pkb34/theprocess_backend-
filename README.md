# theprocess_backend-

## Lydia & Regan journal demo

The [lydia-regan](lydia-regan/) folder contains the FastAPI journal demo and its interactive Swagger UI website.

- `GET /entries` returns all journal entries as a JSON array.
- `POST /entries` accepts a JSON journal entry and returns the created entry.
- `/docs` opens the interactive API documentation and testing page.

### Run locally

Use Python 3.10 or newer. From the repository root, run these commands in Windows PowerShell:

```powershell
cd lydia-regan
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Open <http://127.0.0.1:8000/docs> to create and retrieve journal entries.
See the [demo README](lydia-regan/README.md) for examples and macOS/Linux instructions.

The website is generated by the running FastAPI application. Uploading this repository does not start a public web server. Journal entries are stored in memory and reset when the server restarts.

The existing root-level `main.py` contains the earlier `/items` example. Run `lydia-regan/main.py` for the journal demo.
